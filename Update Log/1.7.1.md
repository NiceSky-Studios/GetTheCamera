# GetTheCamera 1.7.1 Update

## Cloud Restore and Backup

- Added download and restore support for Google Drive cloud files.
- Added 6-hour, daily, and weekly scheduled backup options.
- Added backup status and existing-library backup controls.
- Preserved queue-and-retry behavior for failed uploads.

## Background Transcription

- Added a shared transcript queue that processes clips sequentially.
- Added automatic transcription enqueueing for newly saved clips.
- Added queue controls in Settings.

## Vertical Reel Presets

- Added a 1080x1920 composition path for Vertical Social reels.
