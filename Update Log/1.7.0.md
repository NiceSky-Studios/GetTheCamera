# GetTheCamera 1.7.0 Update

## Cloud Backup

- Extended Google Drive sync with a backup action for the existing clip library.
- Preserved queue-and-retry behavior for failed uploads.
- Kept automatic upload behavior for newly captured clips.

## Smart Highlights

- Added local audio-density highlight scoring after a clip is saved.
- Added `highlight-score` tags and `ai-highlight` tags for high-confidence clips.
- Added the AI Highlights library category.

## Native Sharing

- Added AirDrop, Mail, Messages, pasteboard, and Finder sharing actions to the clip toolbar.

## Export Profiles

- Added Codable custom export profiles persisted through `UserDefaults`.
- Added resolution, frame-rate, quality-preset, and MP4/MOV format settings.
- Added profile selection and management in the reel editor.
