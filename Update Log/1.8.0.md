# GetTheCamera 1.8.0 Update

## Timeline Editor

- Added start/end timeline editing controls to clip playback.
- Added speed changes from 0.5x through 2x.
- Added volume control and exported edited clips back into the library.

## Windows Build

- Added an Electron Windows application under `windows/`.
- Added desktop capture, WebM recording, library browsing, imported clips, and FFmpeg timeline export.
- Added a Windows GitHub Actions workflow for installer and portable packaging.
